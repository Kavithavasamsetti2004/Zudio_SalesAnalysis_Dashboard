# Zudio Sales Analysis Dashboard 📊

## 📌 Project Overview
An Excel-based sales analysis dashboard designed to present key business metrics and compare sales performance across states, clothing types, store types, and product categories.

## 🎯 Project Objectives
- Summarize important sales and business metrics.
- Compare sales performance across different states.
- Analyze performance across the top five clothing types.
- Understand the distribution of rented and owned stores.
- Compare category performance for Kids, Men, and Women.
- Explore store operating hours.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Visualization

## 📈 Key Dashboard Features

### 1. KPI Summary
Displays Total Sales Profit, Max Price, Total Quantity, Total Staff, and Average Sales Profit.

### 2. State-wise Sales Analysis
Compares sales across Delhi, Gujarat, Karnataka, Maharashtra, Rajasthan, Tamil Nadu, Uttar Pradesh, and West Bengal.

### 3. Top 5 Clothing Types
Visualizes sales metrics for Dresses, Jackets, Pants, Skirts, and Sweaters.

### 4. Store Type Distribution
Shows the distribution of rented and owned stores.

### 5. Category Performance
Compares Kids, Men, and Women using sales and quantity metrics.

### 6. Operating Hours Analysis
Presents operating-hour categories for comparing store schedules.
